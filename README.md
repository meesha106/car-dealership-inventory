# Car Dealership Inventory System

## Overview

An inventory management application with a Node.js/TypeScript/Express API,
PostgreSQL persistence, and a React/TypeScript single-page application.

## Requirements

- Node.js and npm
- PostgreSQL

## Setup

Install dependencies separately in each application:

```sh
cd backend
npm install
cd ../frontend
npm install
```

Copy `.env.example` to `backend/.env` and set local values before starting the
backend. The API allows the frontend origin configured by `FRONTEND_ORIGIN`.

## Development

Run `npm run dev` in `backend/` and `frontend/` in separate terminals. Each
application provides `build`, `typecheck`, and `test` scripts. The backend also
provides a coverage script.
